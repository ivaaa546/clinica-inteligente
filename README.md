# Clinica Inteligente

MVP de telemedicina para pacientes, medicos y administradores. Cubre agenda de citas, preconsulta, consulta clinica estructurada, recetas simples, control de acceso por rol y auditoria interna.

## Estado

La especificacion esta en borrador y requiere aprobacion explicita antes de generar un plan tecnico o comenzar la implementacion.
